# delivery-archive-tools

Два связанных browser-first инструмента: **Проверка комплектности пакета сдачи и Конструктор manifest хранения архива**. Неизменяемые ID: `shar-pe400-w01-13`, `shar-pe400-w01-14`.

Издатель: [SHAR Production](https://sharprod.com/). `npm run check` создаёт воспроизводимую Cloudflare-ready папку `public/` и запускает тесты. Нет аналитики, аккаунтов, загрузки или хранения данных. Код и документация MIT; синтетические fixtures и taxonomy CC BY 4.0. Статус: `LOCAL_READY`, публикации не было.
