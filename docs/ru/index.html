Проверка комплектности пакета сдачи

Сопоставляет введённый файловый manifest с обязательными слотами сдачи и правилами имён.

Детерминированные правила
  • Match by declared slot and locale.
  • Validate names without reading file content.
  • Treat extras as review items, not automatic failures.
Границы
Runs in the browser by default; no input upload, analytics, account or persistence.
Инструмент обрабатывает только введённые метаданные и не доказывает содержание файлов или медиа.
Обсудить задачу с SHAR Production ↗
Не вставляйте персональные данные, доступы, подписи и конфиденциальные медиа. Данные остаются в браузере.
